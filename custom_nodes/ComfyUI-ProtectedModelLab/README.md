# ComfyUI Protected Model Lab

Development nodes for loading a generated carrier, verifying a carrier-bound `.spcore`, and applying its direct-LoKr factors through the installed `ModelPatcher` API. The package performs no network requests and does not modify ComfyUI core files.

The current loader is Krea2 diffusion-model-only. Use the workflow's existing Krea2 CLIP and VAE loaders.
